Here are the Key-Value pairs you need to add to your Vercel Project Settings (Environment Variables):

1. **NEXTAUTH_SECRET**
   Value: luxoglobal-super-secret-key-change-me-in-production
   (Or generate a new one with `openssl rand -base64 32`)

2. **NEXTAUTH_URL**
   Value: https://<your-vercel-project-name>.vercel.app
   (In Vercel Preview deployments, this is automatically handled, but for Production, set it to your domain)

3. **DATABASE_URL**
   Value: file:/tmp/dev.db
   (Note: Since Vercel is serverless/read-only, SQLite databases do not persist between function invocations. This configuration uses a temporary copy for demo purposes. For a production app, you MUST switch to a PostgreSQL database like Vercel Postgres, Neon, or Supabase and update this URL to the connection string provided by them, e.g., `postgres://user:password@host:port/database`)

---

If you want to use the included SQLite database for a quick demo on Vercel:
The application has been updated to copy the local database to the temporary directory on startup. Make sure `DATABASE_URL` is set to `file:/tmp/dev.db`.
